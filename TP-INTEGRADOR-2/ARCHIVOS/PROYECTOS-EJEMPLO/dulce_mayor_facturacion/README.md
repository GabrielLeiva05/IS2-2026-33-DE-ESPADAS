# Módulo de Facturación y Reportes JasperSoft - Dulce Mayor (Java 17)

Configurado y optimizado para **Java 17** y Spring Boot 3.2.5 (versión totalmente estable y compatible con el plugin de Maven).

---

## 🚀 Cómo compilar y ejecutar
1. Descomprime este archivo ZIP.
2. Abre tu terminal en la carpeta raíz del proyecto.
3. Ejecuta:
   ```bash
   mvn clean spring-boot:run
   ```
4. Abre en tu navegador o cliente HTTP:
   ```text
   http://localhost:8080/api/facturas/pedido/1/pdf
   ```
