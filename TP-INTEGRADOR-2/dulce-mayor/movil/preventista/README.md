# Dulce Mayor — App del preventista: ruta de visitas en el mapa, alta de clientes y puntos de venta, catálogo y carga de pedidos

React 19 + Vite + React Router + Axios + Leaflet. El código compartido con la otra app está en `../comun` (alias `@comun`).

```bat
copy .env.example .env   &rem VITE_API_URL=http://localhost:8080
npm install
npm run dev              &rem http://localhost:5173
npm run build            &rem genera dist/
npm run lint
```

Documentación completa (flujo, endpoints, mapas, ubicación y qué se verificó): `README.md` en la raíz del proyecto.
